## ✦ Filosofi

Kebanyakan aplikasi to-do mendorong kita mencatat sebanyak mungkin.
**Memento** berangkat dari kebalikannya: daftar yang pendek, jujur, dan
benar-benar bisa diselesaikan. Setiap hari ditandai dengan penanggalan
Romawi dan sebuah aforisme, sebagai pengingat bahwa waktu itu terbatas.

> *"Cukup bukan berarti sedikit."* — Epikuros

## ✦ Fitur

| | |
|---|---|
| 📜 **Penanggalan Romawi** | Tanggal hari ini ditulis dalam angka Romawi, lengkap dengan "hari ke-N dari tahun ini" |
| 💬 **Aforisme berganti** | Kutipan dari Seneca, Epikuros, Hippokrates, dan lainnya, berganti pelan setiap 16 detik |
| ◆ **Tugas utama** | Tandai tugas yang paling penting supaya menonjol dari yang lain |
| ⏰ **Waktu opsional** | Tambahkan jam pada tugas, atau kosongkan saja |
| ✏️ **Edit cepat** | Klik dua kali pada teks tugas untuk mengubahnya |
| ↕️ **Seret & urutkan** | Susun ulang tugas dengan drag and drop (mendukung sentuhan) |
| 🔍 **Filter** | *Semua*, *Menunggu*, atau *Ditunaikan*, masing-masing dengan penghitung |
| 📊 **Bilah progres** | Lihat seberapa banyak yang sudah ditunaikan |
| 🌗 **Mode terang & malam** | Pilihan tema tersimpan otomatis |
| 💾 **Tersimpan otomatis** | Data disimpan di browser lewat `localStorage`, tidak hilang saat ditutup |
| 📱 **Responsif** | Nyaman di ponsel maupun desktop |

## ✦ Cara memakai

**Online**: buka [tautan demo](https://ivandimitri8128-alt.github.io/to-do-list/) di atas.

**Di komputer sendiri**:

```bash
git clone https://github.com/ivandimitri8128-alt/to-do-list.git
cd to-do-list
```

Lalu buka `index.html` di browser. Selesai.

## ✦ Panduan singkat

1. Ketik tugas pada kolom *"Apa yang sungguh perlu dikerjakan?"*
2. (Opsional) Pilih waktu, atau tekan **◆ yang utama** untuk menandainya
3. Tekan **Catat** atau `Enter`
4. Centang tugas yang sudah **ditunaikan**
5. Gunakan **Bersihkan yang ditunaikan** untuk merapikan daftar

## ✦ Teknologi

- **HTML5, CSS3, JavaScript** murni (vanilla), tanpa library atau build tool
- **Google Fonts**: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) untuk judul dan [Inter](https://fonts.google.com/specimen/Inter) untuk teks
- **Web Storage API** untuk penyimpanan data
- **Pointer Events** untuk drag and drop yang berfungsi di mouse dan layar sentuh

## ✦ Struktur proyek

```
to-do-list/
├── index.html    # seluruh aplikasi: markup, gaya, dan logika
└── README.md
```

## ✦ Catatan privasi

Semua data tugas tersimpan **hanya di browser kamu**. Tidak ada server,
tidak ada pelacakan, tidak ada yang dikirim ke mana pun. Menghapus data
situs di browser akan menghapus daftar tugasmu juga.
